
# SecureScan
## Automated Website Security Scanner Using Python

**Developed by:** Chetana S. Tisage

## About the Project

SecureScan is a Python-based automated website security scanner.
It performs basic website security checks and generates reports.

## Features

- URL Validation
- Website Connectivity Check
- HTTPS Detection
- Security Headers Analysis
- CORS Configuration Inspection
- Security Findings Analysis
- JSON Report Generation
- HTML Report Generation

## Technologies Used

- Python 3.13.5
- Jupyter Notebook
- Requests
- JSON
- HTML and CSS

## Installation

1. Install Python.
2. Download or clone this repository.
3. Open Command Prompt in the project folder.
4. Install dependencies:

    pip install -r requirements.txt

5. Start Jupyter Notebook:

    python -m notebook

6. Open ChetanaTisage_SecureScan.ipynb.

## How to Use

1. Open the Jupyter Notebook.
2. Run the cells in sequence.
3. Enter an authorized website URL.
4. Review the security findings.
5. Open the reports folder.
